# Vietnamese Sign Language Recognition ViSL FastAPI Application

## 🐳 Run with Docker

### ⚠️ Requirements
- Make sure you have **Docker** installed.
- **Ensure you have at least 3.29 GB of free disk space**, since the image will occupy approximately this much after building.

### Step 1: Clone repository
```bash
git clone https://github.com/nauxqouh/ViSL-100-words-Recognition-Project.git
cd deploy
```

### Step 2: Build image

```bash
docker build -t visl-fastapi-docker --no-cache .
```
The `--no-cache` parameter ensures Docker always builds the latest build instead of using the old cache.

### Step 3: Run container
```bash
docker run -d -p 8000:8000 --name visl-fastapi visl-fastapi-docker
```
If the terminal returns the container ID, you have run it successfully ✅.

### Step 4: Access API

Open a browser and check:

Check if the API is working:

👉 http://0.0.0.0:8000/

Swagger documentation interface (auto-generated by FastAPI):

👉 http://0.0.0.0:8000/docs

### 🧩 Additional Commands

#### 🛑 Stop container
```bash
docker stop visl-fastapi
```

#### 🔁 Restart container
```bash
docker start visl-fastapi
```
